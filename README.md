# Central Máquinas e Balanças — demonstração

Site institucional demonstrativo, desenvolvido com Vite, JavaScript, CSS, Three.js e GSAP.

## Executar

```bash
npm install
npm run dev
```

Build de produção: `npm run build`. Os arquivos gerados ficam em `dist/`.

## Materiais e critérios

- Marca SVG extraída diretamente do `LOGO.pdf` original fornecido. O PDF também está preservado em `public/assets/`.
- O caso antes/depois foi recortado da peça `1000017970.jpg`. As fotos originais têm ângulos diferentes; o comparador preserva essa diferença e informa a origem.
- As peças dos segmentos são materiais publicitários do ZIP, recortadas para exibir somente os equipamentos e evitar texto promocional antigo. Não indicam estoque atual.
- Não havia foto verificável da fachada ou do interior nos anexos. A busca pública não forneceu imagem com origem e direito de uso suficientemente claros para inclusão.
- O endereço completo diverge entre peças antigas e recentes; a demo mostra somente Lins/SP. Confirmar o endereço antes de eventual publicação.
- A balança/cortador 3D é um modelo conceitual criado com geometria procedural. Não representa um produto específico nem um serviço executado.
- Esta é uma demonstração independente e não foi publicada como site oficial.
